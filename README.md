
About the Project

Quick Quiz is a simple and interactive quiz application designed to test users' knowledge through multiple-choice questions. It provides a quick and easy way to answer questions and check the results.

Features

- Interactive multiple-choice questions
- Easy and user-friendly interface
- Instant answer selection
- Score calculation
- Displays the final quiz result
- Responsive design

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. Start answering the quiz questions.

Objective

The main objective of this project is to create a simple quiz platform that helps users improve their knowledge while providing an interactive and engaging experience.
